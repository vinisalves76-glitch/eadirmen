# EAD Irmen

Sistema para gestao do desenvolvimento de microaulas EAD da Irmen.

## Objetivo

Centralizar o planejamento, distribuicao e acompanhamento da producao de habilidades e microaulas, com perfis de Gerente e Instrutor.

## Perfis

### Gerente
- Criar, editar, excluir e ordenar habilidades
- Classificar por nivel: Basica, Intermediaria, Media e Avancada
- Definir responsaveis
- Montar metas semanais por instrutor
- Acompanhar planejamento, producao, revisao e conclusao
- Gerenciar equipe e usuarios

### Instrutor
- Visualizar habilidades atribuidas
- Consultar metas da semana
- Preencher o planejamento das microaulas
- Atualizar o status de desenvolvimento
- Acompanhar prazos e entregas

## Fluxo inicial

Habilidade -> Microaula -> Planejamento -> Responsavel -> Meta semanal -> Execucao -> Revisao -> Conclusao

## Status do projeto

Prototipo funcional inicial. A proxima fase sera evoluir para autenticacao, banco de dados e permissoes reais.
